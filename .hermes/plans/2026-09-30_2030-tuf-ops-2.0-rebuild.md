### 2.1 Canonical entities (the rebuild's spine)
```

Production Reference      manufacturing handoff
```

### 2.2 Every active object carries (enforced at schema level, not convention)
`state · objective · owner · priority · next_action · next_action_due · blocker · last_activity_at · source · created_by · updated_by`
> **NO MARKET SITS WAITING** — make `next_action` + `next_action_due` **NOT NULL** on Market and RevenueOpportunity so an object cannot exist without a next move.

### 2.3 State machines (implement as typed enums + a transition guard table, not ad-hoc strings)
```
Market Lifecycle
  IDENTIFIED → QUALIFIED → DEVELOPMENT → LAUNCH_READY → PENETRATION
             → ACTIVE → EXPANSION → MATURE            (+ BLOCKED, PAUSED, KILLED)

LETTERED Lifecycle
  IDENTIFIED → QUALIFIED → RIGHTS_PATH → COLLECTION_CONCEPT → COLLECTION_READY
             → STORE_DRAFT → ASSETS_READY → COMMERCE_QA → LAUNCH_READY
             → INSTITUTIONAL_FIRST_LOOK → DECISION_GATE → COLLABORATIVE | COMMUNITY
             → MARKET_SEEDING → LIVE → FIRST_ORDER → TEN_ORDERS
             → TWENTY_FIVE_ORDERS → SCALE → DROP_002   (+ BLOCKED, PAUSED, KILLED)

TEAM UNIFORMS (simple sales lifecycle)
  PROSPECTING → DISCOVERY → DESIGN → QUOTE → DECISION
              → WON → PRODUCTION → DELIVERED → EXPANSION   (+ BLOCKED, PAUSED, LOST)

ISSUE (program apparel lifecycle)
  IDENTIFIED → NEEDS_ASSESSMENT → PROGRAM_DESIGN → QUOTE
             → DECISION → WON → PRODUCTION → DELIVERED → EXPANSION
```

### ACTIVATE MARKET — new product specification (added to 2.0 scope)

Additional schools enter MARKETS **only** through an explicit **ACTIVATE MARKET** operation, which
requires at minimum:

```
market_number          integer, assigned (001, 002, 003, …)
universe reference     the school/universe row this market was activated from
owner                  accountable person
priority               ordinal / tier
objective              what TUF intends to achieve
next_action            the immediate next move        ← required, never null
next_action_due        when it is due                 ← required, never null
activated_at           timestamp of deliberate commitment
```

Once activated, a Market **may contain** LETTERED deployments and/or TEAM UNIFORMS and ISSUE revenue
opportunities. Activation is the single gateway — it is what makes "NO MARKET SITS WAITING" enforceable,
because a Market cannot exist without an owner and a next action.

> **Knowing a school exists does not make it a Market. A Market represents an intentional allocation of
